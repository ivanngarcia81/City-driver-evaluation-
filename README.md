# City Driver Evaluation

Phone app for filling out the City Driver Evaluation forms (Days 1–5) and printing them in the same layout as the paper packet.

- Tap Satisfactory / Needs Improvement / N/A for each item, add comments, and have the driver sign on screen.
- Preview and print one day or all five. Printing builds a PDF and opens the iPhone share sheet (Print, Save to Files, AirDrop), which also works from the home-screen app.
- All driver data stays on the device (browser storage). Use **Back up data** to save a copy.

## Install on iPhone
1. Open the site link in **Safari**.
2. Tap **Share → Add to Home Screen**.
